# Internship Aggregator Platform

A scalable, AI-powered internship aggregation platform using React, Node.js, MongoDB, and Python.

## Features
- **Aggregation**: Listings from LinkedIn, Indeed, WorkIndia, PM Internship Scheme.
- **AI Ranking**: MiniLM and BERT based relevance scoring.
- **Tracking**: Application status tracking dashboard.

## Tech Stack
- Frontend: React (Vite)
- Backend: Node.js + Express
- Database: MongoDB
- AI Service: Python + FastAPI
